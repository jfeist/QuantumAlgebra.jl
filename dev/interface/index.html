QuantumAlgebra.QuantumAlgebra — Module
QuantumAlgebra

Quantum operator algebra: define operators (bosons, fermions, two-level systems, qudits, spins and generators of so(n) and u(n), see @boson etc.) and parameters (@qparam), compute normal forms (normal_form), commutators (comm), vacuum expectation values (vacExpVal), Heisenberg equations of motion (heisenberg_eom, heisenberg_eom_system) and cumulant expansions (expval_as_corrs), and convert the results to LaTeX (latex) or Julia code (julia_expression).

QuantumAlgebra.Corr — Type
Corr(ops::BaseOpProduct)

The correlator (or cumulant) $⟨ops⟩_c$ of a product of operators in a term, i.e., the connected part of the expectation value $⟨ops⟩$ (see expval_as_corrs). Correlators are created with corr, e.g., corr(a'*a) gives ⟨a†() a()⟩c. As the first argument of heisenberg_eom_system, Corr selects equations for correlators.

See also ExpVal.

QuantumAlgebra.ExpVal — Type
ExpVal(ops::BaseOpProduct)

The expectation value $⟨ops⟩$ of a product of operators in a term. Expectation values are created with expval, e.g., expval(a'*a) gives ⟨a†() a()⟩. As the first argument of heisenberg_eom_system, ExpVal selects equations for expectation values.

See also Corr.

QuantumAlgebra.QuExpr — Type
QuExpr

A quantum expression: a sum of terms (QuTerm) with numerical coefficients, which are stored in the dictionary A.terms (from terms to coefficients). The coefficients can be numbers of any type, including symbolic numbers (e.g., from Symbolics.jl or SymPy.jl), and numbers of different types can appear in the same expression.

Expressions are built from operators and parameters (see @boson and @qparam), which are QuExprs themselves, with +, -, *, ^, the adjoint ', sums (∑), and functions such as normal_form, comm or expval. QuExpr() (or zero(QuExpr)) is the empty expression, i.e., zero, and QuExpr(x) is the constant x (e.g., QuExpr(1) == one(QuExpr)).

QuantumAlgebra.Avac — Method
Avac(A, modes_in_vacuum=nothing)
vacA(A, modes_in_vacuum=nothing)

Simplify the expression A acting on the vacuum from the right (Avac, for $A|0⟩$) or from the left (vacA, for $⟨0|A$): Avac(A) returns an expression $A'$ with $A'|0⟩ = A|0⟩$ (and similarly for vacA), where the terms that annihilate the vacuum are removed and operators for which the vacuum is an eigenstate (e.g., $σ^z$) are replaced by their eigenvalues. E.g., Avac(a*a') gives 1, and Avac(a*a'*b[1]) gives 0.

modes_in_vacuum restricts the vacuum to the given modes (the others are left as they are): an operator or a collection of operators, given as the variables defined by the macros (e.g., a after @boson a, or b after @boson b[:], which stands for all modes of b).

QuantumAlgebra.comm — Method
comm(A, B)

Return the commutator $[A,B] = AB - BA$ in normal form. It is computed directly from the commutators of pairs of single operators (with the Leibniz rule), so that the terms of $AB$ and $BA$ that cancel are never generated. E.g., comm(b[:i], b'[:j]*b[:j]) gives δ(ij) b(i) (after @boson b[:]).

QuantumAlgebra.corr — Method
corr(A)

Return the correlator (cumulant) of A, i.e., the operators in each term are wrapped in a correlator $⟨…⟩_c$ (the coefficients and parameters stay outside), e.g., corr(a'*a) gives ⟨a†() a()⟩c. A can be a QuExpr, a QuTerm or a number (which is returned as a constant expression).

See also expval, corr_as_expvals.

QuantumAlgebra.corr_as_expvals — Method
corr_as_expvals(A::QuExpr)

Return the correlator (cumulant) of A expressed through expectation values, the inverse of expval_as_corrs: the operators of each term of A are taken as a correlator, which is written as a sum of products of expectation values. E.g., corr_as_expvals(b'[:n]*b[:m]) gives -⟨b†(n)⟩ ⟨b(m)⟩ + ⟨b†(n) b(m)⟩ (after @boson b[:]). Expectation values and correlators that are already in A are not changed.

QuantumAlgebra.dropcorr — Method
dropcorr(n::Int)

Returns a filter function that rewrites terms with correlations corrs or expectation values expvals of length greater than n in terms of lower-order expressions (up to order n) and higher-order correlators, and then drops those higher-order correlations.

For example, dropcorr(1) will replace $⟨a^† a⟩ = ⟨a^† a⟩_c + ⟨a^†⟩ ⟨a⟩ ≈ ⟨a^†⟩ ⟨a⟩$.

QuantumAlgebra.expval_as_corrs — Method
expval_as_corrs(A::QuExpr)

Return the expectation value of A expressed through correlators (cumulants): the operators $B C D…$ of each term of A are taken as an expectation value $⟨B C D…⟩$, which is written as the sum over all partitions of the operators into products of correlators, $⟨B⟩_c ⟨C⟩_c ⟨D⟩_c… + ⟨B C⟩_c ⟨D⟩_c… + … + ⟨B C D…⟩_c$ (note that $⟨B⟩_c = ⟨B⟩$). Expectation values and correlators that are already in A are not changed.

Examples

julia> @boson b[:];

julia> expval_as_corrs(b'[:n]*b[:n])
⟨b†(n)⟩c ⟨b(n)⟩c + ⟨b†(n) b(n)⟩c

julia> expval_as_corrs(b'[:n]*b[:m]*b[:n])
⟨b†(n)⟩c ⟨b(m)⟩c ⟨b(n)⟩c + ⟨b†(n)⟩c ⟨b(m) b(n)⟩c + ⟨b(m)⟩c ⟨b†(n) b(n)⟩c + ⟨b(n)⟩c ⟨b†(n) b(m)⟩c + ⟨b†(n) b(m) b(n)⟩c

See also corr_as_expvals.

QuantumAlgebra.gellmann — Method
gellmann(q::QuditVariable; sqrt=Base.sqrt)

Return the d²-1 generalized Gell-Mann matrices $λ_1, …, λ_{d²-1}$ of the d-level qudit q (see qudit), with the standard normalization $\mathrm{Tr}(λ_a λ_b) = 2δ_{ab}$ (for a qudit with indices, as objects that are indexed with the indices, λ[1][k]). For k = 2, …, d, these are (in this order) the pairs $|j⟩⟨k| + |k⟩⟨j|$ and $-i|j⟩⟨k| + i|k⟩⟨j|$ for $j = 1, …, k-1$, followed by the diagonal matrix $\sqrt{2/(l(l+1))} (\sum_{m≤l} |m⟩⟨m| - l |l+1⟩⟨l+1|)$ with $l = k-1$. For d = 3, these are the Gell-Mann matrices $λ_1, …, λ_8$ in their usual order. Note that since level 1 is the ground state, for d = 2 they correspond to $(σ^x, -σ^y, -σ^z)$.

The normalization factors $\sqrt{2/(l(l+1))}$ of the diagonal matrices are computed by calling sqrt with the rational number 2//(l*(l+1)) (unless the result is rational, e.g., for l = 1). By default, this gives Float64 numbers. To keep them exact, pass a function that computes the square root symbolically, e.g., sqrt = x -> sqrt(SymPyPythonCall.Sym(x)).

Examples

q = qudit(:q, 3)
λ = gellmann(q)
normal_form(comm(λ[1], λ[2]))  # 2i λ₃
λ[8]                           # 0.57735 - 1.73205 q³³()

QuantumAlgebra.heisenberg_eom — Function
heisenberg_eom(A, H, Ls=())

Return the right-hand side of the Heisenberg equation of motion of the operator A for the Hamiltonian H and the Lindblad terms Ls (with $\hbar = 1$),

\[\frac{dA}{dt} = i [H,A] + \sum_k γ_k \left(L_k^† A L_k - \frac{1}{2} \{L_k^† L_k, A\}\right).\]

The result is not normal ordered (use normal_form). Each element of the tuple Ls describes a Lindblad term (see lindbladterm): (L,) or (γ, L) for the jump operator L with rate γ (1 if it is not given), ((L1, L2),) or (γ, (L1, L2)) for a "mixed" term with two operators (see MixedLindbladTerm), and (:i, γ, L) (or with a tuple of indices) for the sum of the term over the index i.

Examples

julia> @boson a; @qparam ω γ;

julia> normal_form(heisenberg_eom(a, ω*a'*a, ((γ, a),)))
-1//2 γ a() - 1i ω a()

QuantumAlgebra.heisenberg_eom_system — Function
heisenberg_eom_system(H, rhsfilt, Ls=(), ops=nothing)
heisenberg_eom_system(T, H, rhsfilt, Ls=(), ops=nothing)

Return the system of Heisenberg equations of motion for the expectation values (for T = ExpVal, the default) or the correlators (cumulants, for T = Corr) of operator products, for the Hamiltonian H and the Lindblad terms Ls (see heisenberg_eom), as a QuEqSys.

Starting from the operators ops (an operator, or a tuple of operators or products of operators), the equations of all expectation values (or correlators) that appear on the right-hand sides are added until the system is closed. If ops is nothing (the default), the system starts from the annihilation operators that appear in H. Since the equations of products of $n$ operators usually contain products of more operators, the system is truncated by the filter function rhsfilt, which is applied to the right-hand side of each equation and removes higher-order terms or approximates them by lower-order ones (see droplen and dropcorr). An integer n stands for droplen(n).

Examples

julia> @boson a; @qparam ω χ γ;

julia> H = ω*a'*a + χ*a'*(a'+a)*a;

julia> heisenberg_eom_system(H, 2, ((γ, a),), a)
dₜ⟨a()⟩ = -1//2 γ ⟨a()⟩ - 1i ω ⟨a()⟩ - 2i χ ⟨a†() a()⟩ - 1i χ ⟨a()²⟩
dₜ⟨a†() a()⟩ = -γ ⟨a†() a()⟩
dₜ⟨a()²⟩ = -2i χ ⟨a()⟩ - γ ⟨a()²⟩ - 2i ω ⟨a()²⟩

QuantumAlgebra.julia_expression — Function
julia_expression(A, varnames=nothing)

Return a Julia expression (an Expr) that computes the value of A, a QuExpr without bare operators (e.g., with expectation values or correlators). Expectation values and correlators become arrays with a name made from their operators, e.g., $⟨b^†_i b_j⟩$ becomes bᴴb[i,j], parameters become arrays with their names (or, for names like f(t), function calls), Kronecker deltas become I[i,j] (from LinearAlgebra), and summation indices are named s̄₁, s̄₂, … (but the sums are not written explicitly). If the collection of symbols varnames is given, expectation values (or correlators) whose name is not in it are written as the complex conjugate of their adjoint (using $⟨A⟩ = ⟨A^†⟩^*$), e.g., julia_expression(expval(b[:i]), [:bᴴ]) gives conj(bᴴ[i]).

Examples

julia> @boson b[:]; @qparam g[:];

julia> julia_expression(expval_as_corrs(g[:i]*b'[:i]*b[:j]))
:(g[i] * bᴴ[i] * b[j] + g[i] * bᴴb[i, j])

QuantumAlgebra.normal_form — Function
normal_form(A::QuExpr, shortcut_vacA_zero=false)

Return the normal form of A, an equal expression in which the operators of each term are normal ordered (creation operators to the left of annihilation operators, using the algebra of the operators, e.g., $a a^† = 1 + a^† a$), products of operators that simplify are simplified, and the terms are in a canonical form (e.g., summation indices are numbered canonically), so that equal expressions have the same normal form. E.g., normal_form(a*a') gives 1 + a†() a().

If the vacuum $⟨0|$ will be applied from the left (see vacA), shortcut_vacA_zero=true drops the terms that it annihilates during normal ordering already.

See also auto_normal_form, is_normal_form.

QuantumAlgebra.qudit — Method
qudit(name, d::Integer; ndims=0)

Return the qudit (d-level system) name (the function version of @qudit), such that q(i,j) is the transition operator $|i⟩⟨j|$ (with levels 1 ≤ i,j ≤ d). With ndims > 0, the qudit has ndims indices, given as q(i,j)[k,…]. Level 1 is the ground state, i.e., the vacuum.

Internally, all operators are expressed through the "creation" operators $|i⟩⟨1|$ and "annihilation" operators $|1⟩⟨i|$ (with $i ≥ 2$), using $|i⟩⟨j| = |i⟩⟨1|1⟩⟨j|$ and $|1⟩⟨1| = 1 - \sum_{k≥2} |k⟩⟨1|1⟩⟨k|$, which gives a unique normal form. For d=2, q(2,1) and q(1,2) are equivalent to $σ^{+}$ and $σ^{-}$. When printing, products $|i⟩⟨1|1⟩⟨j|$ acting on the same qudit are shown as $|i⟩⟨j|$ (written qⁱʲ).

With a d×d matrix M, q(M) (or q(M)[k,…]) is the operator $\sum_{ij} M_{ij} |i⟩⟨j|$ with this matrix. The entries of M can be numbers or expressions, e.g., parameters. This gives, e.g., the Hamiltonian of a d-level system, or the generators of a Lie algebra in a d-dimensional representation (which then satisfy all the relations of this representation).

Examples

q = qudit(:q, 3)
normal_form(q(1,2)*q(2,3)) # |1⟩⟨3|
q(1,1)                     # 1 - |2⟩⟨2| - |3⟩⟨3|
r = qudit(:r, 3; ndims=1)
r(2,3)[:i]                 # |2⟩⟨3| = |2⟩⟨1|1⟩⟨3| acting on qudit i
# so(3) in the vector representation, (L_k)_ab = -i ϵ_kab, with L² = l(l+1) = 2
Lx, Ly, Lz = q([0 0 0; 0 0 -im; 0 im 0]), q([0 0 im; 0 0 0; -im 0 0]), q([0 -im 0; im 0 0; 0 0 0])
normal_form(Lx^2 + Ly^2 + Lz^2)  # 2
source
QuantumAlgebra.so — Method
so(name, n::Integer; ndims=0)

Return the generators L of the Lie algebra so(n) of rotations in n dimensions (the function version of @so), such that L(a,b) is the generator $L_{ab} = -L_{ba}$ ($a,b = 1,…,n$). With ndims > 0, the generators have ndims indices, given as L(a,b)[k,…]. The generators are Hermitian, with

\[[L_{ab}, L_{cd}] = i (δ_{ac} L_{bd} - δ_{ad} L_{bc} - δ_{bc} L_{ad} + δ_{bd} L_{ac}),\]

as, e.g., for the angular momenta $L_{ab} = x_a p_b - x_b p_a$ of a particle in n dimensions (for n = 3, $(L_x, L_y, L_z) = (L_{23}, L_{31}, L_{12})$). Only these commutation relations are used, so that results hold in any representation. Operators are stored and printed as $L_{ab}$ with $a < b$.

Examples

L = so(:L, 4)
L(2,1)                             # -L¹²()
normal_form(comm(L(1,2), L(2,3)))  # -i L¹³()
source
QuantumAlgebra.spin — Function
spin(name, j=nothing; ndims=0)

Return the operators (Jp, Jm, Jz), i.e., $J_+$, $J_-$ and $J_z$, of the spin name (the function version of @spin), see boson for ndims. They generate the Lie algebra su(2) ≅ so(3), with $[J_z,J_±] = ±J_±$ and $[J_+,J_-] = 2J_z$. If j is not given, only these commutation relations are used, which hold in any representation (e.g., for collective spins). If the spin j is given (any number, e.g., 1//2, 3, or a symbolic variable), products $J_+ J_-$ acting on the same spin are replaced by $j(j+1) - J_z^2 + J_z$, and the vacuum is the lowest-weight state with $J_-|0⟩ = 0$ and $J_z|0⟩ = -j|0⟩$. If j is a number (and not symbolic), all relations of the $(2j+1)$-dimensional representation are used, i.e., also $J_+^a ∏_{m=-j}^{j-a} (J_z - m) = 0$ and $J_-^b ∏_{m=b-j}^{j} (J_z - m) = 0$ (e.g., $J_+^2 = 0$ and $J_z^2 = 1/4$ for j = 1//2), so that the products on one site are $J_+^a J_z^n$ with $n ≤ 2j-a$ and $J_-^b J_z^n$ with $n ≤ 2j-b$.

QuantumAlgebra.un — Method
un(name, n::Integer; ndims=0)

Return the generators S of the Lie algebra u(n) (the function version of @un), such that S(a,b) is the generator $S_{ab}$ ($a,b = 1,…,n$), with $S_{ab}^† = S_{ba}$. With ndims > 0, the generators have ndims indices, given as S(a,b)[k,…]. The commutation relations are

\[[S_{ab}, S_{cd}] = δ_{bc} S_{ad} - δ_{ad} S_{cb},\]

as, e.g., for the collective operators $S_{ab} = \sum_k |a⟩_k⟨b|_k$ of an ensemble of n-level systems (or $S_{ab} = b_a^† b_b$ for bosons $b_a$). Only these commutation relations are used, so that results hold in any representation (e.g., for any number of n-level systems), in the same way as for spins without fixed j (see spin), which are the case n = 2 (with $J_+ = S_{21}$, $J_- = S_{12}$ and $J_z = (S_{22} - S_{11})/2$). For a single n-level system, use a qudit instead (see qudit), whose transition operators satisfy the same commutation relations, but also all relations of the n-dimensional representation. The sum $\sum_a S_{aa}$ commutes with all generators (e.g., it is the number of n-level systems), and the traceless combinations of the generators span su(n).

Products of generators are ordered as the "raising" generators $S_{ab}$ with $a > b$, then the "lowering" generators with $a < b$, and then the diagonal generators $S_{aa}$ (each sorted by $(a,b)$). Vacuum expectation values are not defined.

Examples

S = un(:S, 3)
normal_form(comm(S(1,2), S(2,3)))  # S¹³()
normal_form(S(1,2)*S(2,1))          # S²¹() S¹²() + S¹¹() - S²²()

QuantumAlgebra.vacA — Function
Avac(A, modes_in_vacuum=nothing)
vacA(A, modes_in_vacuum=nothing)

Simplify the expression A acting on the vacuum from the right (Avac, for $A|0⟩$) or from the left (vacA, for $⟨0|A$): Avac(A) returns an expression $A'$ with $A'|0⟩ = A|0⟩$ (and similarly for vacA), where the terms that annihilate the vacuum are removed and operators for which the vacuum is an eigenstate (e.g., $σ^z$) are replaced by their eigenvalues. E.g., Avac(a*a') gives 1, and Avac(a*a'*b[1]) gives 0.

modes_in_vacuum restricts the vacuum to the given modes (the others are left as they are): an operator or a collection of operators, given as the variables defined by the macros (e.g., a after @boson a, or b after @boson b[:], which stands for all modes of b).

Return the vacuum expectation value $⟨0|S^\dagger A S|0⟩$, i.e., the expectation value $⟨ψ|A|ψ⟩$ in the state $|ψ⟩ = S|0⟩$ (which is not normalized automatically). QuantumAlgebra.∑ — Method
∑(ind, A)
∑((ind1, ind2, …), A)

Return the sum of the expression A over the index ind (a symbol such as :i, or an index variable, see @qindex), or over several indices. (∑ is entered as \sum<tab>.) The sum is formal, i.e., the range of the index is not specified. The summed index is replaced by a summation index (see sumindex), so that ∑(:i, g[:i]*b[:i]) is shown as ∑₁ g(#₁) b(#₁).
